## Featured Project

### [FERROSTATS](https://github.com/bapatata688/Ferrostats) — Medallion Data Lakehouse & Streaming Pipeline on GCP

End-to-end data platform built on Google Cloud, designed under Spec-Driven Development.

- **Medallion architecture** (Bronze / Silver / Gold) in **BigQuery**, orchestrated with **Dataform (SQLX)**, with automated data quality assertions and a Star Schema (`fct_daily_sales`, `mart_inventory_pareto_abc`, `dim_products`).
- **Inventory analytics** with BigQuery window functions: Pareto ABC segmentation, burn rate, days of inventory and reorder point, feeding a 3-page **Looker Studio** dashboard.
- **Decoupled OLTP → OLAP streaming ingestion** with UUID idempotency, <50 ms transactional commit latency and 0% overselling.
- **$0.00/mo FinOps architecture** using scale-to-zero **Cloud Run**, keyless IAM Service Account auth and automated Artifact Registry pruning.
